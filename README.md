# 📐 MAI Numerical Methods & Optimization

Сборник лабораторных работ и практических реализаций численных методов по курсу «Численные методы» (МАИ, Институт №8 «Компьютерные науки и прикладная математика», Кафедра 805)[cite: 1].

В репозитории представлены алгоритмы решения систем линейных уравнений, нелинейных систем, задач интерполяции, численного интегрирования и дифференциальных уравнений[cite: 1].

## 🛠 Стек технологий

* **Язык:** Python 3
* **Библиотеки:** NumPy, Matplotlib (для визуализации результатов)
