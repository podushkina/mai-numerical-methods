## 📂 Структура репозитория

### 01. Linear Systems (`/01-linear-systems`)
Прямые и итерационные методы решения систем линейных алгебраических уравнений (СЛАУ) и вычисление собственных значений:
* **`1_1_lu_decomposition.py`** — LU-разложение матриц с выбором главного элемента, вычисление определителя и обратной матрицы
* **`1_2_progonka.py`** — Метод прогонки для трёхдиагональных матриц и проверка условий устойчивости
* **`1_3_iterations_seidel.py`** — Метод простых итераций (МПИ) и метод Зейделя с проверкой сходимости
* **`1_4_jacobi_rotations.py`** — Метод вращений Якоби для поиска собственных значений и векторов симметричных матриц
* **`1_5_qr_algorithm.py`** — QR-разложение матриц (через отражения Хаусхолдера) и QR-алгоритм поиска собственных значений

### 02. Nonlinear Equations (`/02-nonlinear-equations`)
Методы решения нелинейных уравнений и систем нелинейных уравнений:
* **`2_1_nonlinear_equation.py`** — Метод простых итераций и метод Ньютона для нелинейных уравнений (с графическим отделением корней)
* **`2_2_nonlinear_system.py`** — Метод простых итераций и метод Ньютона для систем нелинейных уравнений

### 03. Interpolation & Fitting (`/03-interpolation-and-fitting`)
Приближение функций, сплайны, численные производные и интегрирование:
* **`3_1_lagrange_newton.py`** — Интерполяционные многочлены Лагранжа и Ньютона (разделенные разности)
* **`3_2_cubic_spline.py`** — Построение кубических сплайнов нулевой кривизны (естественные краевые условия)
* **`3_3_mnk.py`** — Метод наименьших квадратов (МНК) для полиномов 1-й и 2-й степени
* **`3_4_numerical_derivatives.py`** — Численное дифференцирование (односторонние и центральные производные 1-го и 2-го порядков)
* **`3_5_numerical_integration.py`** — Численное интегрирование (методы прямоугольников, трапеций, Симпсона) и оценка погрешности по методу Рунге-Ромберга

### 04. Differential Equations (`/04-differential-equations`)
Численное решение обыкновенных дифференциальных уравнений (ОДУ) и краевых задач:
* **`4_1_cauchy_problem.py`** — Решение задачи Коши для ОДУ 2-го порядка (методы Эйлера, Рунге-Кутты 4-го порядка, Адамса)
* **`4_2_boundary_value_problem.py`** — Решение краевых задач для ОДУ 2-го порядка (метод стрельбы и конечно-разностный метод)

## 🚀 Запуск и использование

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/podushkina/mai-numerical-methods.git](https://github.com/podushkina/mai-numerical-methods.git)
   cd mai-numerical-methods
   ```
2. Установите необходимые зависимости:
   ```bash
   pip install numpy matplotlib
   ```
3. Запустите любой нужный скрипт, например:
   ```bash
   python3 01-linear-systems/1_1_lu_decomposition.py  
   ```
